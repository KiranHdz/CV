# CV

Tarea/Actividad de Programacion Web I.

## Publicar con GitHub Pages

1. Ve a **Settings > Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Source: GitHub Actions**.
3. Haz push a `main` (o ejecuta manualmente el workflow **Deploy CV to GitHub Pages** en Actions).
4. Espera a que termine el workflow y abre la URL publicada en la sección de Pages.

Si tu usuario es `KiranHdz`, normalmente la URL será:
`https://kiranhdz.github.io/CV/`
